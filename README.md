# Around The U.S. — React

Aplicación web interactiva desarrollada con React y Vite.

El proyecto permite editar la información del perfil, agregar nuevas tarjetas, eliminar tarjetas, marcar lugares como favoritos y abrir las imágenes en una ventana emergente.

## Funcionalidades

- Editar el nombre y la profesión del usuario.
- Agregar nuevas tarjetas mediante un formulario.
- Eliminar tarjetas.
- Activar y desactivar el botón de “Me gusta”.
- Abrir imágenes en una ventana emergente.
- Cerrar las ventanas emergentes con el botón de cerrar.
- Cerrar las ventanas emergentes al hacer clic sobre el fondo.
- Cerrar las ventanas emergentes con la tecla Escape.
- Diseño adaptable para escritorio, tablet y dispositivos móviles.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- React
- Vite
- Metodología BEM

## Instalación

Clona o descarga el repositorio y ejecuta:

```bash
npm install
```

Después inicia el servidor de desarrollo:

```bash
npm run dev
```

## Scripts disponibles

Iniciar el proyecto:

```bash
npm run dev
```

Comprobar el código con ESLint:

```bash
npm run lint
```

Generar la versión de producción:

```bash
npm run build
```
